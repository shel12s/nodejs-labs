# Lab 6 — P2P аудіочат (WebRTC)

Peer-to-peer аудіочат у реальному часі. Сервер виконує роль сигнального посередника (signaling server) — він лише передає WebRTC-повідомлення між учасниками. Аудіо передається **напряму між браузерами** без участі сервера.

## Стек

- Node.js
- Express
- Socket.io (сигналізація)
- WebRTC (вбудований у браузер API)

## Встановлення та запуск

```bash
cd lab6
npm install
npm run dev     # розробка (nodemon)
# або
npm start       # продакшн (node)
```

Відкрий у браузері: [http://localhost:3000](http://localhost:3000)

> **Примітка:** WebRTC вимагає доступу до мікрофона. Браузер запросить дозвіл при спробі увійти в кімнату. На `localhost` це працює без HTTPS.

## Як користуватись

1. Введи назву кімнати → натисни **Увійти**
2. Браузер запросить доступ до мікрофона — натисни **Дозволити**
3. Відкрий ту саму сторінку в іншій вкладці або на іншому пристрої в тій самій мережі
4. Введи **таку саму назву кімнати** → Увійди
5. З'єднання встановиться автоматично — можна спілкуватись
6. Лог подій у правій панелі показує стан ICE-з'єднання
7. Натисни **Вийти**, щоб покинути кімнату

## Схема сигналізації

```
Учасник B (новий)          Сервер           Учасник A (існуючий)
       |                     |                       |
       |--- join-room ------->|                       |
       |<-- room-joined ------|--- peer-joined ------->|
       |                     |                       |
       |--- offer (→A) ------>|--- offer (from B) ---->|
       |<-- answer (from A) --|<-- answer (→B) --------|
       |                     |                       |
       |<====== ice-candidate (relay обидва боки) =====>|
       |                     |                       |
       |         [RTCPeerConnection: connected]       |
       |         [аудіо передається напряму P2P]      |
```

## Архітектура Socket.io (сигнальний сервер)

| Подія | Опис |
|-------|------|
| `join-room` | Клієнт приєднується до кімнати |
| `room-joined` | Сервер повертає список існуючих пірів |
| `peer-joined` | Сповіщення про нового учасника |
| `offer` | Relay WebRTC Offer |
| `answer` | Relay WebRTC Answer |
| `ice-candidate` | Relay ICE-кандидата |
| `leave-room` | Клієнт покидає кімнату |
| `peer-left` | Сповіщення про вихід учасника |
