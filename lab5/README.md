# Lab 5 — Чат реального часу

Двосторонній чат у реальному часі з авторизацією за іменем, відображенням статусу учасників та системними повідомленнями.

## Стек

- Node.js
- Express
- Socket.io

## Встановлення та запуск

```bash
cd lab5
npm install
npm run dev     # розробка (nodemon)
# або
npm start       # продакшн (node)
```

Відкрий у браузері: [http://localhost:3000](http://localhost:3000)

Для тестування чату відкрий **дві або більше вкладки** браузера за тією ж адресою.

## Як користуватись

1. Введи ім'я (мінімум 2 символи) → натисни **Увійти**
2. Якщо ім'я не пройшло перевірку на сервері — під полем з'явиться повідомлення про помилку
3. Після успішного входу відкривається чат
4. Введи повідомлення (до 300 символів) → натисни **Надіслати** або `Enter`
5. Власні повідомлення відображаються **праворуч**, чужі — **ліворуч**
6. Вхід/вихід учасників відображається як системне повідомлення **по центру**

## Архітектура Socket.io

| Подія | Напрямок | Опис |
|-------|----------|------|
| `message:send` | client → server | Надіслати повідомлення (з acknowledgement) |
| `message:new` | server → all | Розіслати повідомлення всім |
| `user:joined` | server → others | Новий учасник увійшов |
| `user:left` | server → all | Учасник вийшов |
